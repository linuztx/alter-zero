# Technical credits

Alongside the projects acknowledged in the [README](../README.md#acknowledgements), Alter Zero uses these protocols, libraries, and visual resources:

- The [Model Context Protocol](https://modelcontextprotocol.io) for the standard that connects the agent to external tools and services.
- [ratatui-image](https://github.com/benjajaja/ratatui-image) for rendering images inside the terminal.
- [tokio](https://tokio.rs) for the asynchronous event loop.
- [syntect](https://github.com/trishume/syntect) and [two-face](https://github.com/CosmicHorrorDev/two-face) for syntax highlighting.
- OpenAI's [tiktoken](https://github.com/openai/tiktoken) for the `o200k_base` vocabulary used by Alter Zero's token counter.
- [Catppuccin](https://catppuccin.com), [Dracula](https://draculatheme.com), [Nord](https://www.nordtheme.com), [Gruvbox](https://github.com/morhetz/gruvbox), [Solarized](https://ethanschoonover.com/solarized), [Monokai](https://monokai.nl), and One Dark for the palettes behind the themes.
